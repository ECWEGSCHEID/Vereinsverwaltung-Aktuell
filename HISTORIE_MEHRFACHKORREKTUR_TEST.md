# Historie – Mehrfachkorrekturen (Test)

- Im Reiter Historie → Gegenbesuche prüfen und korrigieren können mehrere Zeilen vor dem Speichern bearbeitet werden.
- „Alle Änderungen übernehmen“ (oben und unten) übernimmt alle geänderten Vereinsnamen, Mannschaftszahlen und Nicht-zählen-Häkchen auf einmal.
- Bei einem ungültigen Eintrag wird nichts gespeichert, damit keine Teiländerungen verloren gehen.
- Die Korrekturen bleiben lokal im Browser und können als JSON gesichert werden.
- Originaltermine, Einladungen und Live-Startlisten bleiben unverändert.

**Test:** Drei Namen ändern, zwei Nicht-zählen-Häkchen setzen, einmal speichern, erneut öffnen und eine JSON-Sicherung mit fünf Korrekturen prüfen.
