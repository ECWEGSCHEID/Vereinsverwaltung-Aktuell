# Historie – ein-/ausklappbare Bereiche

Vier Bereiche können unabhängig auf- und zugeklappt werden:
1. Teilnahmen bei uns – Jahresübersicht (standardmäßig offen)
2. Gegenbesuche – Mannschaften pro Jahr (standardmäßig offen)
3. Gegenbesuche prüfen und korrigieren (standardmäßig geschlossen)
4. Turnierdetails (standardmäßig geschlossen, öffnet bei Vereinsauswahl automatisch)

Die bestehende Mehrfachkorrektur, lokale JSON-Sicherung, Einladungen und Live-Startlisten wurden nicht verändert.

Test: ZIP entpacken, Ordner in VS Code als vertrauenswürdig öffnen, index.html mit Live Server starten, Historie öffnen, alle vier Überschriften anklicken. Mehrere Korrekturen speichern und erneut kontrollieren.
