# EC Wegscheid Vereinsverwaltung

Statische Programmdateien für GitHub Pages. Einstieg: `index.html`.
Die vorhandene Firebase-Webkonfiguration verwendet das bestehende Verwaltungsprojekt.

Keine privaten Dokumente oder Datenexporte in dieses Repository legen.
Berichte, Archive und Finanzdaten werden nach Anmeldung aus den vorgesehenen
Speichern geladen. Die JavaScript-Datei der Finanzoberfläche enthält die
Programmfunktion, keine mitgelieferten Finanzaufzeichnungen.

Die vollständige Einrichtung, Firebase-Regeln und Testliste liegen getrennt
im ausgelieferten Komplettpaket. Ordnerstruktur beim Hochladen erhalten.
